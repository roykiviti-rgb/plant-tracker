# 🌱 הצמחים שלי: מעקב השקיה

אתר קטן שזוכר מתי השקיתי כל צמח ומראה מתי צריך להשקות אותו שוב.

## מה יש באתר

- רשימת הצמחים עם תמונה, מסודרת לפי הדחיפות: באיחור, להשקות היום, מחר ובהמשך.
- כפתור „השקיתי” ליד כל צמח, וכפתור „השקיתי את כולם” כשכמה צמחים צריכים מים באותו יום. כל פעולה אפשר לבטל.
- פס „מפלס מים” בכל כרטיס שמתרוקן לקראת ההשקיה הבאה.
- חלון פרטים לכל צמח: השקיה בתאריך אחר, דחייה ביום כשהאדמה עוד לחה, היסטוריית השקיות, טיפים, עריכה ומחיקה.
- סינון לפי מיקום (מרפסת / בבית).
- הוספת צמחים חדשים עם תמונה מהטלפון או אייקון.
- שמירת גיבוי לקובץ וטעינה ממנו.
- עובד גם בלי אינטרנט, ואפשר להוסיף אותו למסך הבית של הטלפון כמו אפליקציה.

## איפה נשמרים הנתונים

בדפדפן של המכשיר (localStorage). אין שרת, אין הרשמה ואין סיסמה.

- הנתונים לא עוברים לבד בין מכשירים. כדי להעביר: „שמירת גיבוי” במכשיר אחד ו„טעינת גיבוי” בשני.
- כדאי לשמור גיבוי מדי פעם. ניקוי נתוני הדפדפן מוחק את הרשימה.
- התמונות של הצמחים ההתחלתיים הן חלק מהאתר, ולכן כל מי שיש לו את הקישור יכול לראות אותן. תמונות של צמחים שמוסיפים באתר נשמרות רק במכשיר.

## העלאה לאינטרנט עם GitHub ו-Vercel

1. **GitHub**: נכנסים ל-[github.com/new](https://github.com/new), נותנים שם (למשל `plant-tracker`), בוחרים Private, **בלי** README, ולוחצים Create repository.
2. **שליחת הקוד**: בתיקיית הפרויקט מריצים (עם הכתובת של המאגר החדש):
   ```bash
   git remote add origin https://github.com/<שם-משתמש>/plant-tracker.git
   git push -u origin main
   ```
3. **Vercel**: נכנסים ל-[vercel.com](https://vercel.com) עם חשבון GitHub ‏→ Add New ‏→ Project ‏→ Import ליד המאגר ‏→ Deploy. אין צורך לשנות הגדרות: הקובץ `vercel.json` כבר אומר ל-Vercel להגיש את תיקיית `public`.
4. מעכשיו כל `git push` לענף `main` מעדכן את האתר אוטומטית תוך כדקה.

## התקנה בטלפון

- **אייפון (Safari)**: כפתור השיתוף ‏→ „הוספה למסך הבית”.
- **אנדרואיד (Chrome)**: תפריט ⋮ ‏→ „התקנת האפליקציה” או „הוספה למסך הבית”.

באייפון כדאי לפתוח את האתר מהאייקון במסך הבית: כך הנתונים נשמרים בצורה יציבה יותר.

## הרצה במחשב

צריך [Node.js](https://nodejs.org). אין חבילות להתקנה.

```bash
npm run dev
```

ואז פותחים את http://localhost:5173. בדיקות אוטומטיות:

```bash
npm test
```

## איפה משנים מה

| מה | איפה |
| --- | --- |
| הרשימה ההתחלתית (נטענת רק בפעם הראשונה במכשיר) | `public/js/seed.js` |
| תמונות הצמחים | `public/plants/` |
| עיצוב וצבעים | `public/css/styles.css` |
| התנהגות האתר | `public/js/app.js` |
| חישובי תאריכים וסטטוס | `public/js/logic.js` |

אם מוסיפים לרשימה ההתחלתית צמח עם תמונה, כדאי להוסיף אותו גם לרשימה בראש `public/sw.js`, כדי שהתמונה תוצג גם בלי אינטרנט. כשיש אינטרנט האתר תמיד טוען את הגרסה העדכנית, כך ששינויים מופיעים מיד.
