# 🌱 הצמחים שלי: מעקב השקיה

אתר שזוכר מתי השקו כל צמח, מראה מתי צריך להשקות שוב, ושולח תזכורת לטלפון בבקרים שיש מה להשקות.

## מה יש באתר

- רשימת הצמחים עם תמונה, מסודרת לפי הדחיפות: באיחור, להשקות היום, מחר ובהמשך.
- כפתור „השקיתי” ליד כל צמח, וכפתור „השקיתי את כולם” כשכמה צמחים צריכים מים באותו יום. כל פעולה אפשר לבטל.
- פס „מפלס מים” בכל כרטיס שמתרוקן לקראת ההשקיה הבאה.
- חלון פרטים לכל צמח: השקיה בתאריך אחר, דחייה ביום כשהאדמה עוד לחה, היסטוריית השקיות, טיפים, עריכה ומחיקה.
- סינון לפי מיקום (מרפסת / בבית), הוספת צמחים עם תמונה מהטלפון או אייקון, וגיבוי לקובץ.
- **רשימה משותפת** ב-Firebase: כל מי שפותח את האתר רואה את אותה רשימה, ושינויים מתעדכנים אצל כולם מיד.
- **תזכורת יומית**: כל בוקר בין 7 ל-9 מגיעה התראה לכל טלפון שהפעיל אותה, רק אם יש צמחים להשקות.
- עובד גם בלי אינטרנט (השינויים נשלחים כשהחיבור חוזר), ואפשר להתקין אותו במסך הבית של הטלפון.

## איך זה בנוי

| חלק | איפה | מה הוא עושה |
| --- | --- | --- |
| האתר | `public/` ב-Vercel | דף אחד בלי שלב בנייה |
| הנתונים | Firebase Firestore | הרשימה המשותפת, `gardens/main` |
| התזכורת | `api/remind.js` ב-Vercel | רץ כל בוקר (ב-`vercel.json`), בודק מה צריך מים ושולח התראות |
| בדיקת התראה | `api/test-push.js` | הכפתור „שליחת התראת בדיקה” |

אם `firebaseConfig` ב-`public/js/config.js` הוא `null`, האתר שומר הכול רק בדפדפן של המכשיר, בלי שרת.

## הקמה

### 1. Firebase

1. ב-[console.firebase.google.com](https://console.firebase.google.com) יוצרים פרויקט (אפשר בלי Google Analytics).
2. **Firestore Database ← Create database**: מיקום Tel Aviv (`me-west1`) או `eur3`, במצב production.
3. בלשונית **Rules** מדביקים את כל התוכן של `firestore.rules` ולוחצים **Publish**.
4. בהגדרות הפרויקט מוסיפים אפליקציית Web ‏(`</>`) ומעתיקים את `firebaseConfig` אל `public/js/config.js`.

הרשימה פתוחה לכל מי שיש לו את כתובת האתר, בלי התחברות. כללי האבטחה מאפשרים לשמור רק נתונים במבנה של האתר, כדי שאי אפשר יהיה להשתמש במסד הנתונים לשום דבר אחר.

### 2. Vercel

1. מחברים את המאגר ב-GitHub לפרויקט ב-Vercel. אין צורך לשנות הגדרות, כי `vercel.json` כבר מגדיר הכול.
2. ב-**Settings ← Environment Variables** מוסיפים את `VAPID_PRIVATE_KEY`. הערך נמצא בקובץ `.env.local` שבמחשב: זה המפתח הסודי לשליחת התראות, ו-git לא מעלה אותו.
3. אפשרות נוספת: `CRON_SECRET` עם מחרוזת אקראית כלשהי. כך רק Vercel יוכל להפעיל את התזכורת היומית.
4. אחרי שמוסיפים משתנים צריך פריסה חדשה: לוחצים **Redeploy**, או דוחפים commit.

כדי ליצור זוג מפתחות חדש מריצים `node scripts/generate-vapid-keys.js --force`, ומעדכנים את המפתח הציבורי ב-`config.js` ואת הסודי ב-Vercel. אחרי החלפה, כל טלפון צריך להפעיל את התזכורת מחדש.

## התקנה בטלפון והפעלת התזכורת

- **אייפון (iOS 16.4 ומעלה)**: ב-Safari ← כפתור השיתוף ← „הוספה למסך הבית”. פותחים את האתר מהאייקון, ושם לוחצים „הפעלת תזכורת”. באייפון התראות עובדות רק מהאפליקציה שבמסך הבית.
- **אנדרואיד (Chrome)**: תפריט ⋮ ← „התקנת האפליקציה”, ואז „הפעלת תזכורת”.

אחרי ההפעלה מגיעה התראת בדיקה. אם היא הגיעה, הכול מחובר.

## הרצה במחשב

צריך [Node.js](https://nodejs.org). אין חבילות להתקנה.

```bash
npm run dev
```

ואז פותחים את http://localhost:5173. השרת המקומי מגיש רק את האתר, בלי `api/`, ולכן שליחת התראות עובדת רק באתר שב-Vercel. בדיקות אוטומטיות:

```bash
npm test
```
